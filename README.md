# ANAquant

Projet d'Analyse Quantitative et de Trading Algorithmique.

## Structure du projet

- `data/` : Données brutes et nettoyées
- `notebooks/` : Exploration Jupyter
- `src/` : Code source principal (données, stratégies, backtest, modèles)
- `tests/` : Scripts de validation
- `logs/` : Journaux d'exécution

## Démarrage rapide

1. Créer un fichier `.env` basé sur `.env.example`.
2. Activer l'environnement virtuel.
3. Lancer `python tests/test_config.py` pour valider la configuration.
